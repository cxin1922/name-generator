隱私權政策

本頁說明「取個好名」在使用站內取名工具、瀏覽文章頁與 FAQ 頁時，如何處理輸入內容與瀏覽器本機資料。

工具輸入與本機處理

使用站內取名工具時，候選名字的產生全部在瀏覽器裡完成。使用者選擇的性別、字數、寓意祝福、小說分類、角色氣質等條件，不會被傳送到任何伺服器。「取個好名」沒有後端資料庫，也沒有帳號系統，無法得知任何使用者輸入或選擇了什麼內容。

這不代表瀏覽本站完全沒有網路資料傳輸。瀏覽器載入網頁、字型檔案，或執行流量統計程式（詳見下方 Cloudflare Web Analytics 說明）時，網站主機與相關的網路服務商，通常會接收到 IP 位址、請求時間、瀏覽的頁面網址、瀏覽器與裝置類型等基本技術資訊。這些屬於瀏覽網頁時必然產生的技術性資料，並非「取個好名」主動額外蒐集。

瀏覽器本機儲存空間（localStorage）：收藏功能

候選卡片上的「收藏」功能，會把收藏的名字存在目前使用的瀏覽器的 localStorage 裡，是存在裝置本機的資料，不會上傳、不會跨裝置或跨瀏覽器同步，也不會被「取個好名」讀取或蒐集。換裝置、清除瀏覽器資料，或關掉隱私/無痕視窗之後，這些收藏都可能遺失，這點在 FAQ 頁也有說明。想完全清除，可以從瀏覽器設定裡刪除本網站的網站資料。

分享連結

候選卡片的「分享」「分享全部」功能，是把候選名字編碼進網址參數裡，不需要帳號或後端資料庫。點開分享連結後，瀏覽器會直接從網址解碼出同一批候選名字並顯示出來，這段資料只存在於網址本身，不會額外傳到「取個好名」的伺服器（本站沒有伺服器端的資料處理）。

網站流量統計：Cloudflare Web Analytics

本站託管在 Cloudflare 上，並在 Cloudflare 的帳號後台開啟了 Cloudflare Web Analytics。開啟後，Cloudflare 會在正式網站的頁面上自動加入一段統計程式（static.cloudflareinsights.com/beacon.min.js），這段程式不在本站自己的原始碼裡，但瀏覽本站時確實會執行。

依 Cloudflare 官方的說明，這項服務不使用追蹤用的 Cookie，也不收集可以識別個人身分的資料，只統計訪客數、頁面瀏覽量這類基本的流量數字，用來了解大概有多少人在用、哪些頁面比較常被看，不會用於辨識個人身分，也不會跟工具裡選擇的條件產生關聯（這些條件本來就只留在瀏覽器裡）。

Google Analytics 與 Google AdSense

「取個好名」目前尚未串接 Google Analytics（GA4）或 Google AdSense，網站上還沒有任何會追蹤訪客行為的 Google 分析或廣告程式碼，也還沒有使用與廣告相關的 Cookie。首頁放了一個 Google Search Console 用來確認網站擁有權的驗證標籤，這個標籤只在 Google 核對網站擁有權時用到，不會蒐集或追蹤任何訪客資料。

之後如果加入 GA4 做網站使用狀況的統計，或加入 AdSense 顯示廣告，會在這兩項服務實際上線的同時更新本頁，具體說明會蒐集哪些資料（例如頁面瀏覽、約略地理區域、瀏覽器類型等整體使用情況）、Google 與其廣告夥伴如何使用 Cookie 投放個人化廣告，以及如何透過 Google「我的廣告中心」管理或關閉個人化廣告。在那之前，這部分的說明都還不適用。

第三方服務與外部連結

本站目前的網站託管與網路基礎設施，由第三方服務提供，這些服務會依其自身的條款與隱私權政策處理技術性的連線資料。文章頁內部連結皆為本站頁面；若點擊連到本站以外的網站，該網站的資料處理方式由其自己的政策規範，不受本頁約束。

未成年人的隱私

「取個好名」的服務對象是一般大眾。寶寶取名工具雖然是為了幫新生兒取名而做，實際使用者多半是準備迎接孩子的爸媽或家人。本站本來就不需要註冊，也不主動蒐集任何個人資料，所以不會刻意蒐集未成年人或兒童的資料；為寶寶選擇的性別、寓意等條件，同樣只在瀏覽器裡處理。

政策更新與聯絡方式

如果本站之後新增帳號系統、跨裝置同步，或任何新的分析、廣告服務，會依實際上線的功能更新本頁內容，不會讓說明跟網站實際的運作方式不一致。
